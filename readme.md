# Проект для управления питанием платы чтения счётчиков

Контроллер ATMega48PA, без кварца. 
Включает питание на ESP32 и SIM800 раз в заданное время, по сигналу выключает, и спит заданное число минут-часов-дней в режиме минимально возможного потребления тока от батареи. Не даёт включить, если батарея разряжена.
Батарея литиевая 4В. Управление таймерами по I2C, можно настроить время срабатывания и прочитать напряжение и счётчики работы (общее время + количество пробужений + зона для хранения инфы есп32 до перезагрузки)

При подаче питания отрабатываем логику первого включения

## Распиновка

| Пин  | Обозначение | Описание                                                             |
|------|-------------|----------------------------------------------------------------------|
| PB0  | I2C_PULLUP  | Включает подтяжки I2C-линии высоким уровнем                          |
| PC0  | BATT_VOLT   | Измерение напряжения батареи                                         |
| PD2  | POWER_CTRL  | Включение питания высоким уровнем                                    |
| PD5  | MCU_TRIG    | Триггер для откл. питания. Подтяжка вверх, активно - низкий уровень. |
| PC4  | I2C_SDA     | Данные I2C                                                           |
| PC5  | I2C_SCL     | Синхросигнал I2C                                                     |

## Протокол I2C

Интерфейс I2C-слейва: память 32 байта. Адрес настраивается в конфиге. Например 0x15 (7 бит).

Карта регистров:
| Смещение | Шир. | Обозначение | Описание                                      |
|----------|------|-------------|-----------------------------------------------|
| 0        | 1    | STATUS      | Текущий статус                                |
| 1        | 1    | ---         | Зарезервированная зона под расширение статуса |
| 2        | 2    | PERIOD      | Период пробуждения в минутах                  |
| 4        | 2    | VOLTAGE     | Напряжение батареи                            |
| 6        | 2    | COUNTER     | Количество пробуждений от батареи             |
| 8        | 4    | TIME        | Время в секундах (примерно) от запуска        |
| 12       | 4    | ---         | Зарезервировано                               |
| 16       | 16   | MEM         | Память для заметок ESP32                      |

### STATUS (регистр 0)

Биты текущего статуса:
| Бит | Обозначение | Описание                                        |
|-----|-------------|-------------------------------------------------|
| 0   | FIRST_START | Первый запуск - активно до первого сна          |
| 1   | LOW_VOLTAGE | Напряжение около границы постоянного отключения |
